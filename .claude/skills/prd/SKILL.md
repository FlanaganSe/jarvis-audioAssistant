# PRD Skill

Create or update a Product Requirements Document.

## Process

1. Read `docs/requirements.md` for existing context
2. Ask clarifying questions if the scope is unclear
3. Write/update the PRD in `.claude/plans/prd-{feature}.md`
4. Include: problem, user stories, acceptance criteria, out-of-scope, open questions
5. Get user confirmation before proceeding
