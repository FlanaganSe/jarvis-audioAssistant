# Complete Skill

Finalize a feature after all milestones are done.

## Process

1. Run `/verify` to confirm all checks pass
2. Run `/review` for a final code review
3. Update `docs/decisions.md` with any architectural decisions made
4. Update `docs/SYSTEM.md` if the system architecture changed
5. Summarize what was built, decisions made, and any follow-up items
