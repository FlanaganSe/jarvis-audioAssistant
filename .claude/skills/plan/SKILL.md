# Plan Skill

Create a step-by-step implementation plan.

## Process

1. Read relevant PRD and research notes from `.claude/plans/`
2. Break work into milestones (each independently shippable)
3. Write the plan to `.claude/plans/plan-{feature}.md`
4. Each milestone should include: goal, files to create/modify, acceptance criteria
5. Get user approval before starting implementation
