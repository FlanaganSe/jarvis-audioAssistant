# Research Skill

Perform focused research and write up findings.

## Process

1. Clarify the research question with the user
2. Search the codebase, web, and documentation
3. Write findings to `.claude/plans/research-{topic}.md`
4. Include: summary, options considered, recommendation, trade-offs, sources
5. Present findings and get user input before acting on them
